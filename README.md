# szcore_vehiclekeys

Advanced SzCore vehicle-key system for v1.4.0-rc1.

Features: owner/shared/temporary keys, synced locks, engine control, key transfer, job/shared vehicle access, world vehicle lock state, hotwire, key search, lockpick, carjack, reconnect/session keys and police alerts.

Dependencies: `oxmysql`, `szcore`, `szcore_vehicles`, `szcore_ui`, `szcore_inventory`.
